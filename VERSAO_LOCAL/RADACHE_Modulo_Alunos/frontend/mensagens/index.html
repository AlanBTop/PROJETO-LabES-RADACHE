RADACHE · ENGENHARIA DE SOFTWARE

Conversas que conectam.

Protótipo acadêmico inspirado no WhatsApp Web para validar a comunicação de mensagens do RADACHE.

Ao enviar, a mensagem aparece imediatamente. Um POST com JSON é disparado para a API local; a confirmação ou falha aparece na própria mensagem.

Os dados são fictícios. O histórico enviado fica na memória desta aba e é reiniciado ao recarregar. A confirmação do mock não indica entrega ao destinatário nem persistência no banco.
