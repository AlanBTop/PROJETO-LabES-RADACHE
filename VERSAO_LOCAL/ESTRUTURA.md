# Estrutura da versão local

| Caminho | Responsabilidade |
|---|---|
| INICIAR_LOCAL.bat | Inicializador para Windows |
| portal/ | Entrada e navegação |
| gestao/ | Gestão de chamados, equipe e acessos |
| institucional/ | Observatório agregado |
| painel-demo/ | Painel analítico |
| assets/ | Estilos, fontes e ícones compartilhados |
| RADACHE_Modulo_Alunos/frontend/ | Interface de alunos e mensagens |
| RADACHE_Modulo_Alunos/backend/ | Servidor, regras e testes |
| RADACHE_Modulo_Alunos/database/ | Esquema e dados fictícios iniciais |
| scripts/ | Utilitários de manutenção e verificação |

Bancos gerados, logs e dados de histórico são mantidos localmente e não fazem parte do repositório. Alguns scripts alteram dados; utilize o inicializador para a apresentação.
